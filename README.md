# persian-writer

A Claude skill that writes natural Persian (Farsi) text.

## Install

Copy this folder to `~/.claude/skills/persian-writer`:

```bash
git clone https://github.com/Ariiima/persian-writer ~/.claude/skills/persian-writer
```

## What it does

- Writes native-sounding Persian, not word-by-word translation.
- Uses correct half-spaces, Persian digits, and Persian punctuation.
- Matches formal or colloquial register.
